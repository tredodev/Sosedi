# Соседи (Тредо)

Приложение для жителей ЖК: отключения, «Кто перекрыл авто», мастера, барахолка, опросы, заявки и взносы ОСИ, голосования, общие зоны и другие сервисы дома. В репозитории две вещи:

| Папка | Что это |
| --- | --- |
| `src/`, `build.mjs` | Рабочая пилотная версия: приложение жителя, кабинет председателя ОСИ и модерация Тредо в одном файле с общей базой данных. |
| `prototype/`, `pwa/` | Кликабельный прототип 60 экранов в дизайн-системе Соседей 2022 года. Без базы, открывается в любом браузере и устанавливается на телефон как приложение (PWA). |

## Где работает рабочая версия

Рабочая версия написана как опубликованный артефакт claude.ai. База данных, аккаунты пользователей, загрузка фото, скачивание файлов и пересказ чатов приходят из среды claude.ai через объект `window.claude`. Вне claude.ai приложение откроется, но покажет «Откройте приложение в claude.ai и войдите». Репозиторий нужен, чтобы хранить код, вести историю изменений и переносить продукт на собственный стек (см. `docs/port-plan.md`).

Текущая публикация: https://claude.ai/artifact/VyWWtnjftGkB9fCJFypDhw

## Сборка

Зависимостей нет, нужен только Node.js 18+.

```bash
node build.mjs        # или npm run build
# -> dist/index.html (один самодостаточный файл)
```

Сборка склеивает `src/template.html`, стили из `src/styles/` и скрипты из `src/js/` в порядке номеров в именах файлов. Порядок важен: модули объявляют глобальные константы и используют их друг у друга.

## GitHub

Workflow `.github/workflows/build.yml` на каждый push в `main` собирает приложение, кладёт сборку в артефакт запуска (Actions → запуск → Artifacts → `sosedi-build`) и публикует прототип на GitHub Pages. Тег `v*` создаёт релиз с архивом сборки. Для Pages один раз включите Settings → Pages → Source: GitHub Actions.

## Скачать сборку из GitLab

Каждый запуск CI собирает `dist/index.html` и `dist/capabilities.json`. Последняя сборка ветки `main`:

```
https://<gitlab>/<группа>/<проект>/-/jobs/artifacts/main/download?job=build
```

Для версии создайте тег (например, `v0.3.0`): появится релиз в разделе Deploy → Releases с прямыми ссылками на архив и на `index.html`.

## Установить прототип на телефон

CI публикует прототип на GitLab Pages вместе с манифестом, иконками и офлайн-кэшем (`pwa/`). Откройте адрес из Deploy → Pages на телефоне. Android, Chrome: меню → «Установить приложение». iPhone, Safari: «Поделиться» → «На экран Домой». После установки прототип открывается без адресной строки и работает без сети. Каждая новая сборка меняет версию кэша, и телефоны получают обновление при следующем открытии с интернетом.

## Публикация в claude.ai

Соберите `dist/index.html` и опубликуйте его как артефакт с возможностями из `capabilities.json` (правила базы, загрузка фото участниками, скачивания, пересказ, данные пользователя). Если обновляете уже опубликованный артефакт, его база и данные сохраняются.

## Структура

```
src/
  template.html              оболочка страницы: шрифт, переключатель режимов, контейнеры
  styles/
    01-design-system.css     токены и компоненты дизайн-системы Соседей 2022, светлая и тёмная темы
    02-app.css               оболочка, формы, админки
  js/
    01-kit.js                иконки и базовые элементы интерфейса
    02-core.js               платформа, подписки на базу, роутер, рендер, общие хелперы
    03-resident-1.js         житель: вход, главная, лента, барахолка, публикации, приглашения, уведомления
    04-resident-2.js         житель: машины, мастера, чаты, объявления ОСИ, заявки, взносы, голосования
    05-resident-3.js         житель: сервисы и аккаунт
    06-actions.js            все действия, которые пишут в базу
    07-catalog.js            классификатор городов, справочник ЖК, выбор города и ЖК, лист ожидания
    08-osi.js                кабинет председателя ОСИ (#osi)
    08b-features.js          чек-лист первого дня, «Меня затапливает», настройки уведомлений и тихие часы,
                             очередь «Хочу забрать» с бронью, справочник дома, объявление по фото
    08c-services.js          пропуск курьеру и «Пост охраны», «Помогите с машиной», места во дворе,
                             заказ на подъезд и кабинет поставщика, служебный вход по коду
    09-admin.js              модерация Тредо (#admin), обработчики событий и запуск
data/seed/
  zk.json                    справочник ЖК на момент выгрузки (записи с test: true — тестовые, адреса не проверены)
  platform-settings.json     тарифы и настройки платформы
prototype/index.html         прототип 60 экранов
capabilities.json            возможности и правила базы для публикации артефакта
docs/
  architecture.md            устройство приложения и модель данных
  port-plan.md               ограничения пилота и план переноса на Expo + Supabase + Next.js
.gitlab-ci.yml               сборка и GitLab Pages (прототип в корне, сборка приложения в /app)
```

## Входы и роли

| Адрес | Кто | Доступ |
| --- | --- | --- |
| `#app` | житель | любой участник артефакта (уровень «Участник» и выше) |
| `#osi` | председатель ОСИ | роль `osi` у жителя ЖК (назначает модератор) или редактор артефакта |
| `#admin` | модератор Тредо | владелец и редакторы артефакта |
| служебный вход | охрана, поставщик | код от председателя ОСИ (охрана) или модератора (поставщик), вход без адреса квартиры |
| `#invite-<жк>-<код>` | приглашение соседа | подтверждает адрес без кода подъезда |
| `#showcase-<жк>` | витрина ЖК | публичная страница, доступна и для просмотра без записи |

## Данные в репозитории

В `data/seed/` только справочник ЖК и настройки платформы. Профили жителей, переписка, заявки и голоса в репозиторий не выгружались. Полную выгрузку текущего ЖК делает модератор в разделе «Тредо» → «Данные» → «Скачать JSON»: в ней есть личные данные жителей, хранить её в общем репозитории нельзя.

## Важные ограничения пилота

Права ролей ОСИ и модератора проверяет интерфейс, а не правила базы, и любой участник технически может прочитать общие данные ЖК, включая личные сообщения. Оплаты подтверждаются вручную, пушей и SMS нет, домофон и камеры не подключены. Подробно в `docs/port-plan.md`.
